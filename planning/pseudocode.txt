# Required queries

# Query 1: List doctors at a selected hospital
BEGIN
Identify hospital_id to be used.
Retrieve hospital_id, person_id and name from hospitals table and doctors_patients table. 
Match hospitals to doctors using hospital_id
DISPLAY list of doctors at selected hospital

# Query 2: List a patient's prescriptions by date
BEGIN
Identify patient_id to be used
Retrieve prescription_id, medication, prescription_date, person_id and name from prescriptions table and doctors_patients table.
Match prescriptions to the patient using person_id.
Order results by prescription_date
DISPLAY the results.

# Query 3: List all prescriptions issued by a selected doctor
BEGIN
Identify doctor_id to be used.
Retrieve prescription_id, medication, person_id and name FROM prescriptions table and doctors_patients table.
Match prescriptions to the doctor using doctor_id to parson_id  WHERE role is Doctor.
DISPLAY list of prescriptions issued by a doctor

# Query 4: Add a new patient and assign a doctor
BEGIN
Check that the selected doctor_id belongs to a Doctor
Insert the new patient details
Assign the selected doctor_id to the patient
Automatically generate the next person_id
Check that the patient was added successfully

# Query 5: Identify the doctor with the most prescriptions issued
Retrieve person_id, name and prescription_id FROM prescriptions table and doctor_patients table.
Group prescriptions by doctor
Count the prescriptions for each doctor
Order the counts from highest to lowest
Display the doctor with the highest count

# Query 6: List doctors at the largest hospital by bed number
Find the maximum hospital size
Select the hospital with that size
Retrieve hospital_id, name, size, person_id and name FROM hospitals table and doctors_patients table WHERE hospital size = MAX(size).
Match the hospital to its doctors using hospital_id
Display all doctors at that hospital
